## Alcance

Propuesta académica de infraestructura **100 % AWS** con VPC, subredes, frontend, Laravel, Keycloak, bases de datos, Suricata, Wazuh y auditoría. Los diagramas reflejan la arquitectura objetivo; no deben interpretarse como evidencia de que todos los recursos hayan sido desplegados y validados.

**Nota académica:** Si la rúbrica del perfil de egreso solicita un centro de datos híbrido (con componentes locales), una propuesta solo AWS no satisface por completo ese requisito y requiere aprobación o adaptación.

No se incluyen contraseñas, credenciales ni claves AWS.
