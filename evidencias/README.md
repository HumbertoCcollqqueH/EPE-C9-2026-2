# Evidencias de validacion (pendientes)

Estas carpetas son para actas, capturas, logs sanitizados, pruebas y aprobaciones del equipo.
Las carpetas vacias se mantienen en Git con `.gitkeep`.

NO publiques nombres reales de clientes, contrasenas, datos de contacto, tokens AWS, archivos .env o secretos. Antes de subir capturas, oculta datos sensibles.

Una carpeta vacia no demuestra que la prueba fue ejecutada. Las evidencias seran aportadas y revisadas por el equipo.
